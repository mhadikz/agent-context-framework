# Brand & Persona Guidelines

## Core Persona
- The target audience includes [e.g., operators and end users of one product line].
- The tone must be clear and specific. The same error code always maps to the same user sentence.

## Copy Writing Constraints
- **Do Write:** Actionable sentences and stable API codes (`ORDER_ALREADY_PAID` with `This order has already been paid.`).
- **Do Not Write:** Ambiguous failures, internal exception names, or a different message for the same code in each squad's UI.
- Admin actions that change permissions or money use plain language that matches the audit event name.
