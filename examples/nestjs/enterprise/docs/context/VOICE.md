# Brand & Persona Guidelines

## Core Persona
- The target audience includes partner engineers, internal product teams, and operators.
- The tone must match the platform catalog. The same code means the same sentence in every context.

## Copy Writing Constraints
- **Do Write:** Catalogued codes, one human sentence, and audit phrases that match the API verb.
- **Do Not Write:** Context-local slang, raw downstream errors, or messages that leak whether a protected resource exists.
- Deprecations name the sunset version and the replacement.
