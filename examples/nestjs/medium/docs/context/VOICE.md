# Brand & Persona Guidelines

## Core Persona
- The target audience includes external API consumers, partner engineers, and on-call operators.
- The tone must be consistent across modules. One code, one sentence.

## Copy Writing Constraints
- **Do Write:** Stable codes and short sentences. Admin audit text uses the same verb as the API action.
- **Do Not Write:** Per-squad wording for a shared error, stack traces, or vendor error payloads forwarded raw to clients.
- Deprecation notices name the removal version and the replacement field.
